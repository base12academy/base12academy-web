# Archivo recuperable: Beca Ménace

Fecha de archivo: 25 de julio de 2026.

Esta carpeta conserva las dos páginas completas tal como estaban inmediatamente antes de retirar de la web la Beca Ménace:

- `home-con-beca.tsx`: página principal con el enlace de navegación, bloque informativo, pregunta frecuente y estilos.
- `historia-espana-con-beca.tsx`: página del curso con el enlace a la Beca Ménace.

La versión también puede recuperarse desde Git mediante el commit `a785ba8`.

Para restaurarla de forma segura, debe recuperarse únicamente el bloque `beca-menace`, su enlace de navegación, la pregunta frecuente y los estilos `scholarship*`; no conviene sustituir la página completa si después se han realizado otros cambios.
